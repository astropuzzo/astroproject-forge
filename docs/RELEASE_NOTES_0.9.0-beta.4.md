# AstroProject Forge 0.9.0-beta.4

## English

This beta focuses on clarity and first-use confidence.

- One **Menu** now contains language, interface size, project commands, help, diagnostics and About.
- WBPP instructions show only the required Grouping Keyword rows and explain each one in plain language.
- About identifies the author, copyright and GitHub repository, with a transparent AI-assisted vibe-coding notice.
- **Quick guide** opens the project wiki; **Report a problem** opens a guided form that does not require technical knowledge.
- Italian and English documentation and screenshots have been refreshed.

Original image files remain read-only. Review calibration assignments before processing valuable data.

## Italiano

Questa beta punta su chiarezza e semplicità al primo utilizzo.

- Un solo **Menu** raccoglie lingua, dimensione interfaccia, comandi progetto, aiuto, diagnostica e informazioni.
- Le istruzioni WBPP mostrano soltanto le Grouping Keyword necessarie e spiegano in modo semplice a cosa servono.
- La pagina Informazioni identifica autore, copyright e repository GitHub e dichiara in modo trasparente lo sviluppo tramite vibe coding assistito da AI.
- **Guida rapida** apre la wiki; **Segnala un problema** apre un modulo guidato che non richiede competenze tecniche.
- Documentazione e screenshot italiani/inglesi sono stati aggiornati.

I file immagine originali restano in sola lettura. Controlla le assegnazioni di calibrazione prima di elaborare dati importanti.
